# Assets

Static files referenced by `app.json` and the UI.

| Kind | Location | Notes |
|------|----------|--------|
| App icon / splash | `tcc-logo.png`, `android-icon-background.png` | Paths in `app.json` |
| Fonts | `@expo-google-fonts/poppins` | Loaded in `app/_layout.tsx` |
| Future illustrations | this folder | Keep PNG/SVG exam branding here |

Do not commit large binary backups; use consistent lowercase-kebab names.
