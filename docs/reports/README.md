# Archived investigations

Point-in-time bug hunts and implementation write-ups, kept for the audit trail.

They quote file paths **as they were when the report was written**, before the
move to `features/` + `shared/`. Use [../FEATURE_MAP.md](../FEATURE_MAP.md) to
find where a module lives now — for example `services/offlineStore.ts` is today
`features/synchronization/services/offlineStore.ts`.

The findings and root causes are still accurate; only the paths moved.
