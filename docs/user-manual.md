# Mobile user manual (short)

## Applicant

1. Join the examination Wi‑Fi.
2. Open the app → Take Examination → scan QR or type the room code.
3. Confirm identity, enter passkey, wait in the lobby.
4. When the proctor starts, answer items. Do not leave the app.
5. Submit. Questions are removed from the phone.

## Proctor

1. Sign in **online** (email/password or Google).
2. Examination tab → download **Today’s Exam Pack**.
3. On campus Wi‑Fi, open the room for the time slot (Not opened → Lobby open).
4. Show QR / code. Start the exam when the roster is ready.
5. End the session. Sync results when internet is available.
6. **Ended** means you finished that room — not that the clock passed.
